# mainframe// — downloads

Installers and in-app update files for **mainframe//** by etern.kv —
compiled binaries only. The source code is private; nothing here is a
build input. Downloads are offered at [etern-kv.net](https://etern-kv.net).

| system | file (always the latest) |
|---|---|
| Windows 10 (1903) or 11, x64 | [mainframe-windows-x64-setup.exe](https://github.com/eternKV/mainframe-releases/releases/latest/download/mainframe-windows-x64-setup.exe) |
| macOS 13.3 or later, Apple Silicon | [mainframe-macos-arm64.dmg](https://github.com/eternKV/mainframe-releases/releases/latest/download/mainframe-macos-arm64.dmg) |
| Linux (glibc 2.39+: Ubuntu 24.04, Debian 13, Fedora 40 or later), x86-64 | [.deb](https://github.com/eternKV/mainframe-releases/releases/latest/download/mainframe-linux-amd64.deb) · [.rpm](https://github.com/eternKV/mainframe-releases/releases/latest/download/mainframe-linux-x86_64.rpm) · [AppImage](https://github.com/eternKV/mainframe-releases/releases/latest/download/mainframe-linux-x86_64.AppImage) |

Each release lists `SHA256SUMS` for every file. Installed copies update
themselves when you choose to: every update file is signed, and the app
installs only what verifies against the key built into it.
`latest.json` is what the app reads to learn of a new version.

The voice and the built-in model are separate downloads inside the app,
each pinned by SHA-256; they are not part of these files and are kept
across updates.
